# BulStepTech — образовательная платформа

**Версия:** v2.0 · 2026-07-16 · [Живая демонстрация →](https://romver2002.github.io/bulsteptech_frontend/)

Учебная платформа с «премиальным» тёмным интерфейсом: живые лекции-трансляции,
каналы-чаты, задания, тесты, аналитика успеваемости, микрообучение и профиль.
MVP на моковых данных (бэкенд не подключён).

## Возможности

- **Роли и вход** — выбор роли «Студент»/«Преподаватель», защита маршрутов по
  ролям (`vue-router`), доступные каналы фильтруются под роль.
- **Трансляции** — единый ролевой `StreamView` (для студента и преподавателя):
  управление эфиром, демонстрация экрана, список участников, реакции, чат.
- **Каналы и чат** — сообщения и реакции хранятся в Pinia-store и переживают
  переключение каналов; вложения, поиск, режим «только чтение» для объявлений.
- **Задания** — доска заданий с прогрессом и отметками задач.
- **Аналитика** — графики успеваемости (Chart.js, tree-shaking + ленивая загрузка).
- **Обучение** — микрообучение и интерактивные квизы.
- **Интерфейс** — тёмная тема (glassmorphism), уведомления, адаптивная вёрстка.

## Технологии

- Vue 3 (`<script setup>`) + Vite 6
- Pinia — состояние
- Vue Router — маршрутизация и guard'ы
- Tailwind CSS 3 — стилизация
- Chart.js — графики (грузятся только на канале аналитики)

## Начало работы

```bash
npm install      # зависимости
npm run dev      # разработка (http://localhost:3000)
npm run build    # продакшн-сборка в dist/
npm run preview  # просмотр собранного билда
```

Тестовый вход: любое имя пользователя, роль выбирается кнопками.

## Деплой на GitHub Pages (CI/CD)

При пуше в `main` GitHub Actions
([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)) собирает проект
и публикует `dist/` на GitHub Pages.

- Базовый путь в проде — `/bulsteptech_frontend/` (в [`vite.config.js`](vite.config.js)).
- Для прямых ссылок `vue-router` (history) при сборке создаётся `404.html`
  (SPA-fallback).
- Адрес: `https://romver2002.github.io/bulsteptech_frontend/`.

> Первый деплой: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
